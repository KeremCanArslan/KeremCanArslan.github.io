SEO Rapor: privacy policy

Last updated: 6 November 2026

SEO Rapor is an internal reporting tool run by Kerem Can Arslan (Ankara, Türkiye). It is not a public service: only the operator signs in with it, to prepare search performance reports for website owners who have given the operator access to their own Google Search Console or Google Analytics property.

What the tool accesses

  • Google Search Console, read-only (webmasters.readonly): search clicks, impressions, queries, pages and indexing status of the properties the signed-in account can access.
  • Google Analytics, read-only (analytics.readonly): traffic and conversion figures of the properties the signed-in account can access.

The tool does not change any setting, site, sitemap or account.

How the data is used

The data is used only to produce the monthly report for the owner of that website. It is not sold, not used for advertising and not shared with anyone other than that website owner. The report text may be written with the help of an AI assistant (Anthropic Claude); Google user data is not used by us to develop, improve or train AI models.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

Sign-in tokens and report files are stored only on the operator's own computer. Report data for a website is deleted when work for that website ends. A website owner can remove access at any time in Search Console (Settings, Users and permissions) or Google Analytics (Admin, Property access management), and the signed-in account can revoke the tool at myaccount.google.com/permissions.
